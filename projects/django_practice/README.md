# Практики к лекции 4.1

Команды запускаются из папки `projects/django_practice`.
Для запросов к PokéAPI и Dog API нужен интернет.

## Практика 1. Покемоны

```text
python practice_1.py
```

Программа выводит первые 20 покемонов. Введите имя из списка,
например `clefairy`, чтобы посмотреть характеристики.

## Практика 2. Фотографии собак

```text
python -m pip install -r practice_2/requirements.txt
python practice_2/manage.py runserver
```

Откройте http://127.0.0.1:8000/ и введите породы через запятую,
например `african, chow, dingo`.

## Практика 3. Команда покемонов

```text
python practice_3.py
```

Добавьте двух покемонов, например `pikachu` и `bulbasaur`.
Для тренировочного боя выберите пункт 5 и введите их имена.
Побеждает покемон с большей суммой базовых характеристик.
Команда хранится в памяти до выхода из программы.
