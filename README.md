# Репозиторий для практических работ по программированию

## проект калькулятор

Проект находится в папке `projects/calculator`.

Калькулятор:

- запрашивает два числа и знак операции;
- выполняет сложение, вычитание, умножение и деление;
- не допускает деление на ноль;
- выводит целое число, если результат деления не имеет остатка;
- сообщает о неизвестной операции.

## проект шифр Цезаря

Проект находится в папке `projects/Шифр_Цезаря`.

Шифр Цезаря:

- принимает текст из нескольких строк до ввода пустой строки;
- позволяет выбрать русский или английский алфавит;
- принимает числовой ключ сдвига;
- умеет зашифровывать и расшифровывать текст;
- удаляет пробелы и основные знаки препинания;
- выводит исходный текст и результат преобразования.
